# DDoS-Detection-System

Real-time DDoS Detection System using Java with burst, global and multi-IP detection.

## Technologies Used
Java, Python, Flask, Scapy, HTML, CSS, JavaScript, Chart.js, Apache Server

## Features
- Real-time packet monitoring
- Threshold-based DDoS detection
- Live dashboard visualization
- Attack simulation for testing
- Email alert system for administrators

## Working
The system monitors incoming network packets and evaluates traffic volume.
If requests exceed a threshold, it flags the traffic as a potential DDoS attack
and alerts are shown on the live dashboard.
